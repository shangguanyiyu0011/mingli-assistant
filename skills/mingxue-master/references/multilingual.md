# 多语言填写与报告

填写页支持 `zh-CN`、`en`、`ja`、`ko`。切换只更新界面文字，保留用户输入、上传照片、真实牌序、每个人和主题的选填问卷。方法名、牌名有译名，提交的稳定标识和实际抽取结果保持原值。

`preferences.ui_language` 记录填写页语言。`preferences.language` 可为 `auto` 或上述四种语言；明确选择优先。自动时先识别用户问题，再识别本人说明的主要语言；文字不足时采用填写页语言。不得从中文系统标签、姓名或出生地点单独推断正文语言。结果的 `questionnaire._report_language` 是经过校验后生成的报告语言记录，表单答题不能覆盖它。

Agent读取交接记录后，按该语言撰写每种方法、综合主题、行动和双人分析。专业名称可保留必要原文，并用报告语言说明具体含义。HTML界面与PDF采用同一报告语言；已有旧任务没有语言字段时沿用中文，不为了补默认值改写旧任务或使签名失效。

## 姓名的适用方式

不按界面语言、国籍或外貌分类。汉字姓名经用户确认姓／名后，继续使用旧格式：

```json
{"surname":"林","given":"安","strokes":[8,6]}
```

`strokes` 可省略并由既有字库查询，以上仅为合同示例，不作为查字结果。现代笔画不冒称康熙折算。

国际姓名使用：

```json
{"mode":"international","full_name":"Alex Morgan","latin_name":"Alex Morgan","pronunciation":""}
```

`full_name` 保留本人实际写法；`latin_name` 和 `pronunciation` 可省略。原名本身由拉丁字母组成时，可复用现有的 `name_expression`；日文、韩文及其他文字只使用本人提供的拉丁写法，不自行音译。字母法只支持已有A–Z映射，无法映射的字符不硬转。

国际结果的 `five_grids`、`three_talents` 为 `null`；界面隐藏汉字笔画和姓／名拆分要求。报告可说明写法、实际提供的读音，以及有真实字母计算结果时的表达数；没有字母结果时不假造数理或凑五格。双人比较分别采用双方实际适用的方法，不能把不同方法的数字当成同一种量相减或合分。其他体系仍按资料是否充足决定，不因界面语言改变适用范围。
