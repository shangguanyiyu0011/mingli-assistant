# 预设插画与互动牌面

所有插画由内置图片模型生成，按敦煌青金风格统一，离线随包使用。完整提示词、图集窗口、尺寸和真实摘要见 `assets/art-manifest.json`；不包含个人照片、用户肖像或出生资料。

塔罗78张分别有独立场景：22张大阿卡纳，以及权杖、圣杯、宝剑、星币各14张。雷诺曼36张也各有对应图案。牌背统一。四花色总览另外只作装饰，不能代替各张小牌。卷首山水和三枚铜钱用于视觉层次，不代表真实出生盘、实际硬币或新的抽取结果。

牌面是原创意象绘图，部分画面里的器物数与牌号数字不完全相同；牌名、序号、牌位、正逆位及解释依据都来自实际牌组记录，不从图像推断。图集只有在 `verified_for_card_binding:true` 且准确牌名或 `card_id` 唯一命中时才可贴到某张牌。优先使用 `atlas.tiles` 的实际像素窗口，保持原比例并裁切视口，不露相邻牌，不把重复窗口包装成不同牌。

`reader_art.py`核对随包图片后，为最终HTML内嵌本次实际需要的图集。资料表通过同源地址读取随包插画；它的图片地址不会带入最终离线HTML。不可把示例插画当作用户上传的手掌、人像或住宅照片。

用户亲自点击抽牌或摇卦后，将实际结果交给原生手工牌序/爻序，不在服务器再抽。后续修改关注主题、追加文字或切换人数不自动重抽；需要新开时由用户明确清除并重新开始。双人使用同一组牌时明确这是对共同问题的一次抽取，不当成两次独立证据。

## 手相、面相原照AI标注

用户的手掌和人像照片须先实际查看，按本人保存可见特征并绑定当前照片引用。用户要求原照划线、编号时，默认调用宿主内置图片生成模型，以该张原照为参考编辑标注；生成前先明确各编号对应的真实部位和观察，不为模糊处补造纹路。生成后逐处核对，文字观察仍以原照为依据，不把生成的新细节当成证据。生成图只存用户工作区，不加入插件源码、预设插画或打包素材。

原图图库继续遵守逐张 `include_in_report`。用户明确要求原照标注，是对带标注辅助图的授权，可在该条图记录使用 `use_original_photo:true`；这不授权另附没有标注的原照图库。没有这项授权时，只能使用不复刻可识别肖像的独立通用示意图。不能把原照改名冒充生成图，文件摘要与结构检查也不代替实际视觉核对。

`finalize`、`deliver` 的 `--illustrations` 接受UTF-8数组，最多4条。原照AI标注每条严格包含下面九个字段；照片标识和摘要来自本人当前 `photo_refs`，图片路径指向实际生成的编辑结果：

```json
[
  {
    "person": "A",
    "system": "palm",
    "result_sha256": "本人当前面板的64位小写摘要",
    "image": "D:\\报告工作区\\标注图\\A-手掌.png",
    "sha256": "实际生成标注图的64位小写摘要",
    "caption": "1 掌心横纹；2 拇指根部；3 掌缘。",
    "photo_id": "本人原照的实际标识",
    "photo_sha256": "该张上传原照的64位小写摘要",
    "use_original_photo": true
  }
]
```

HTML、无脚本正文和PDF均标明“原图AI标注”，并避免重复原图图库。标注是模型生成的辅助图，不声称照片像素完全不变。只在用户明确选择其他方式时切换提供方或使用矢量标注。

## 独立通用示意图

`finalize(..., illustrations_file=...)`、`deliver(..., illustrations_file=...)` 与 CLI `--illustrations` 接受 UTF-8 JSON 文件，顶层严格为数组，最多4条；每条恰含以下六字段：

```json
[
  {
    "person": "A",
    "system": "palm",
    "result_sha256": "对应本人当前面板的64位小写摘要",
    "image": "D:\\报告工作区\\示意图\\A-手掌.png",
    "sha256": "这张生成图文件的64位小写SHA-256",
    "caption": "掌缘的弧线是这次可见的重点，细小纹路没有补画。"
  }
]
```

- `person` 仅为本次实际存在的 `A` 或 `B`；`system` 仅为 `palm` 或 `face`。摘要须与本人的当前 `result_sha256` 一致，改过观察后的旧图清单不能沿用。
- 本人当前结果须为 `agent_observed`，有非空 `features` 和 `photo_refs`；引用照片的标识、摘要、人物及手掌/人像类型都须正确，相关面板须已能供读者阅读。
- `image` 须为现存本机绝对 `.png`、`.jpg` 或 `.jpeg` 文件，每张不超过8 MiB，实际 PNG/JPEG 结构及真实摘要须通过检查。拒绝 SVG、URL、`file://`、UNC、设备路径、相对路径、上级路径、符号链接与目录联接、插件或运行时目录内素材。同一图不得重复或跨人共用，也拒绝与本次任一原照片摘要相同的文件。映射网络盘无法跨平台统一识别，调用者应选择本机磁盘。
- `caption` 为1—500字，不含本机路径或控制字符。所有条目在开始写交付文件前校验；错误不会生成这一轮交付版本。

最终报告在对应 `panel.illustrations` 内嵌已验证图片的 data URI、图注和标注类型，不加入生成图路径。原照AI标注另保留 `source_photo_id` 用于图库去重。单人和双人分别保持原人物归属；无 JavaScript 时的正文也保留图和图注。报告为完整离线文件，不读取外部图片。
