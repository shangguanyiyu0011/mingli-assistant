# 可选本地盘面工具

5.0.0 的主流程是 [Agent 一次性收集与报告交接](agent-workflow.md)。使用者填一次资料表，提交后回到 Agent，由 Agent 计算、补问与解读，交付个人及双人离线 HTML。最终报告不含资料填写页。本页描述供 Agent 排查和单项探索的可选本机盘面工具。

## 打开

需要单项探索时，在技能根使用 `launch.cmd workbench`。启动器寻找实际存在的 CPython 3.12 / 64位，不使用 WindowsApps 空别名。启动后由 Agent 打开实际返回的 `http://127.0.0.1:<端口>/workbench`。根地址是资料表；`/workbench` 才是单项盘面工具。保持执行会话，结束时只关闭本次服务。没有兼容 Python 时会明确返回准备提示，不会全局安装软件。

从 Agent 调用时，首选在宿主浏览器打开实际返回的本地地址；本机页面无法使用时可打开系统浏览器。页面自动取得同源会话令牌，不需要用户复制令牌；不要输出、保存到报告或外传令牌。一次性资料收集请使用 `agent_intake`，不要用单项工作台替代主流程。

命令行可指定 `--port`，默认0让系统选择空闲端口。只监听127.0.0.1，不提供公网地址或远程账号功能。出生资料、问题及历史记录只在本机处理。

## 操作

1. 左侧选择体系；搜索框按名称、分组和功能筛选。
2. 按真实资料填写表单。示例按钮仅填演示数据，不代表用户资料，也不会自动开始计算。提问时空与出生时空分别填写。
3. 选择规则、起式或牌阵，点击生成。涉及随机方法时，实际执行抽样并记录种子；手工结果与抽样不能混用。
4. 查看盘面、规则及原始数据。资料不确定时分别列候选，用户选择后才显示该候选盘，不据此宣称已确定真实时刻。紫微流运与土占的多种图形是视图切换，区别于不确定候选。
5. 从历史重新打开结果和输入，或导出JSON、静态HTML和存在的SVG图形。打印使用浏览器打印，可按本机浏览器支持另存PDF。

默认记录目录为 Windows `%LOCALAPPDATA%/mingxue/workbench`，与插件安装文件分开；`MINGXUE_WORKBENCH_DATA` 或 `--data-dir` 可指定新的外部绝对目录。每条记录绑定输入、方法、原始结果和盘面的SHA-256，读取时核对；冲突或损坏的记录不会混入历史列表。该校验用于发现变更，不是抵御已控制本机文件系统的攻击者。

## 按需准备

占星与七政/卜卦占星共用已固定版本的外置星历引擎；紫微、姓名字库及太乙分别准备。界面只有点击“准备依赖”才执行下载；日常计算不会自动联网。所需依赖、解释器和数据均在插件外缓存，按固定版本及哈希验证。

太乙因原生历法库的平台要求，使用隔离的官方 Python3.11 Windows x64嵌入运行时；主插件仍由Python3.12运行。这些文件不会安装到全局Python。太乙支持1900—2100年、明确的中国UTC+08钟点；分钟/命法未开放。某些零局规则边界返回不支持，不擅自换算法。详细限制见各方法说明。

## 批量与CLI

原有 `workflow` 和命令仍保留。新增方法统一写为：

```text
launch.cmd fortune xiaoliuren --params "{\"mode\":\"numbers\",\"numbers\":[3,5,7]}"
```

不同shell的引号规则可能不同；复杂参数优先由JSON文件的调用脚本读取，不在shell中拼接用户内容。批量项目输入使用 `options.<方法ID>.params` 对象，例如：

```json
{"schema_version":1,"systems":["xiaoliuren","yilin"],"options":{"xiaoliuren":{"params":{"mode":"numbers","numbers":[3,5,7]}},"yilin":{"params":{"method":"pair","base":1,"changed":2}}}}
```

Web表单为常用参数做扁平化，CLI的`params`采用各模块原生JSON，二者以方法文档为准。跨体系只比较结构与解释依据，不投票生成命运分数或预测概率。
