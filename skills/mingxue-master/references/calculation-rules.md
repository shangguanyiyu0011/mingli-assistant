# 结构化基础盘的计算约定

`scripts/pillar_details.py` 的 `build_details(pillars)` 接受 `year`、`month`、`day`、`hour` 四个字段。每项必须为合法六十甲子或 `null`。这部分计算只描述输入符号的关系，不参与公历、农历、时区或真太阳时换算。

返回 `complete`、`missing_pillars`、`day_master`、逐柱 `pillars`、`relations` 和 `chosen_convention`。逐柱包含干支五行阴阳、藏干、相对日干的十神、纳音和十二长生。日干对自身的十神记为“比肩”，`is_day_master` 单独标记日柱。未知柱保持 `null`；日柱未知时，所有依赖日干的十神和十二长生也为 `null`。

藏干次序与包内历法库一致，巳支采用丙、庚、戊；不赋予比例。十二长生采用阳顺阴逆、戊随丙和己随丁：甲起亥、乙起午、丙戊起寅、丁己起酉、庚起巳、辛起子、壬起申、癸起卯。土干寄宫等存在传承差异，这里记录选定约定，不称为唯一标准。

天干五合记录甲己、乙庚、丙辛、丁壬、戊癸。地支表如下：

|关系|采用的组合|
|---|---|
|六合|子丑、寅亥、卯戌、辰酉、巳申、午未|
|六冲|子午、丑未、寅申、卯酉、辰戌、巳亥|
|六害|子未、丑午、寅巳、卯辰、申亥、酉戌|
|六破|子酉、丑辰、寅亥、卯午、巳申、未戌|
|三合|申子辰（水）、亥卯未（木）、寅午戌（火）、巳酉丑（金）|
|三会|寅卯辰（木）、巳午未（火）、申酉戌（金）、亥子丑（水）|

三合、三会必须三种地支齐全才记录完整关系，不将两支称为完整三合或三会。括号中五行为传统表项，仅作关联标签，不意味着已经合化。不同关系可以并存，不自行抵消。

刑采用寅→巳→申→寅、丑→戌→未→丑定向两支刑，另记子卯互刑。`group_complete` 标明相应三支是否齐全，只有两支时仍可记录两支刑，不称三刑齐全。自刑只采用辰、午、酉、亥，且同支至少出现在两个柱位。本表为选定规则，并不宣称涵盖所有流派。

每条关系的 `positions` 与 `characters` 逐项对应。普通关系按年、月、日、时排列；定向刑按施刑→受刑排列。重复地支保留实际柱位，三支组有重复成员时分别输出每个实际柱位组合，不丢弃重复位置。缺柱时仅使用已知柱，不能据此认定完整出生盘没有其他关系。

这里不提供五行分数、旺衰结论、喜忌、合化成立判断、命运结论或预测概率。十神、纳音、藏干和十二长生已逐表、逐组合对照包内历法库；结构符号匹配本身不构成事件预测的验证。
