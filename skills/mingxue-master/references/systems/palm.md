# 手相：可见线条、形态与传统术语

状态：`reference_only`。已整合手相术语、观察步骤、质量检查和报告协议；本包不从图像自动识别掌纹，也不提供个人命运测定。辅助工具 `scripts/visual_intake.py` 只检查本地图片容器、尺寸及方向元数据，保存显式输入。

## 适用与输入

适用于掌纹名称辨认、图像中可见形态描述，以及《神相全编》等传统相书术语的文化解释。只使用本轮实际可见的图片或用户明确描述；不得从姓名、账号、其他人物照片、身份或个人记忆补足观察事实。

- 图片可一手一张，掌面朝向镜头，手掌自然展开；掌根、指根和掌缘尽量完整，光线均匀，避免美颜及强反光。
- 左右手由用户说明，未说明填 `unknown`。镜像、自拍翻转、惯用手单独记录；不能仅凭拇指在画面哪边就认定解剖学左右。
- 清晰度、透视、裁切、遮挡、阴影分别检查。被阴影遮住或分辨率不足的线条写“无法辨认”，不能写成“没有这条线”。
- 无图时可解释用户所述形态，但观察状态必须为 `not_observed`，措辞为“按你的描述”。左右手的传统先后天说法仅作为流派观点，不当作事实；不采用“男左女右”确定手别或结论。
- 不要求用户提供性别、年龄、职业、健康史或家庭情况来补全照片。

## 观察词表

先定位，再描述方向、长度在掌面中的相对范围、线条是否可分辨、分叉及连续性。照片无法可靠判断触感、手掌软硬或干湿；颜色会受白平衡和曝光影响，不转为健康判断。

| 可见区域 | 常见传统名称 | 可描述内容 | 文化词义的说明方式 |
|---|---|---|---|
| 拇指根部外围弧线 | 生命线、地纹 | 弧度、范围、是否能连续追踪 | 名称包含“生命”，不表示能测寿命或体质 |
| 掌心中部横向或斜向线 | 智慧线、头线、人纹 | 走向、分支、与邻线是否交叠 | 传统以“思考”为主题，不能据此评智力或能力 |
| 指根下方的上部横线 | 感情线、心线、天纹 | 起止区域、走向、可见分叉 | “情感”是象征主题，不能据此判忠诚或关系经历 |
| 掌根朝中指方向的纵线 | 命运线、事业线 | 纵向位置、是否断续可辨 | 是传统名称，不等于职业、收入或未来事件 |
| 无名指下的纵向线 | 太阳线、成功线 | 单条或多条、可辨范围 | “名望/表达”仅是文献主题，不能据此判成功 |
| 手掌轮廓和手指外缘 | 方形、圆形、细长等形态描述 | 图中轮廓及相对比例，附透视限制 | 不把手型归类转成人格、道德或职业类型 |

名称容易混淆：中部横线通常从拇指与食指之间附近向掌心延展，上部横线通常较接近指根。不同流派命名、细分和起止点不完全一致；不能确认时使用位置描述，保留候选名称。不要把掌心中线误标为从小指下开始的上部横线。

## 掌丘术语

掌丘是传统对掌面区域的命名。可说明“食指根部区域常称木星丘”“中指根部称土星丘”“无名指根部称太阳丘”“小指根部称水星丘”“拇指根部肉垫称金星丘”“小指侧掌根附近称月丘”。火星丘的分区在流派间有差异，需注明口径。

这些是文化标签，不是可从照片检测出的“能量”。只描述图中区域轮廓，不把隆起、平坦或纹路多少换算成领导力、诚实程度、性欲、疾病或财运。

## 处理步骤

1. 标明 `image_observed` 或 `not_observed`，列出图片/用户描述的来源，先检查质量和手别。
2. 按实际可分辨部位分别写清位置、走向、弯曲、深浅差异、连续范围与邻线关系，不能只列“弯曲、圆形”等词。可靠可辨才谈分叉和连接；局部限制随对应部位一句说明，不用常见掌纹模板补齐。
3. 根据位置给出传统名称候选，明确“名称辨认”和“传统主题说明”。
4. 如果用户问个性、能力、家庭、职业前景、婚姻次数、健康或寿命，说明图片无法支持该推断；可继续提供形态描述及一般文化词义。
5. 比较左右手时仅比较可见线条，不能把差异解释为“后天改变命运”。

## 输出协议

| 字段 | 内容 |
|---|---|
| `status` | 本模块 `reference_only`；图像观察另有状态 |
| `observation_status` | 实际看图为 `image_observed`；仅用户描述为 `not_observed` |
| `hand` / `dominant_hand` | 用户明确值或 `unknown` |
| `quality` | 清晰度、光线、裁切、遮挡、镜像/滤镜情况；各项标观察来源 |
| `visible_features` | 部位、可见形态、辨认限制；没有依据的项不填 |
| `traditional_terms` | 名称及一般文献主题，不接个人预测 |
| `limits` | 这张图片不能支持哪些观察 |

合适示例：“拇指根部外侧的弧线沿肉垫弯向掌根，中央部分较清楚，腕侧逐渐变浅；此位置在传统术语中常称生命线或地纹。”

## 本地图片输入工具

```text
python <skill_root>/scripts/visual_intake.py --system palm --image <local.png> --observations <observations.json> --output <intake.json>
```

`observations.json` 的值由用户明确提供，示例：

```json
{
  "hand": "left",
  "dominant_hand": "right",
  "quality": {"clarity": "unknown", "cropping": "partial", "occlusion": "unknown"},
  "features": [{"region": "thumb_arc", "shape": "curved", "visibility": "clear"}]
}
```

手相区域键：`palm_outline`、`thumb_arc`、`middle_transverse`、`upper_transverse`、`central_vertical`、`ring_finger_vertical`、`finger_outline`、`palm_pad`。形态键为 `straight|curved|branched|interrupted|parallel|round|angular|long|short|wide|narrow|unresolved`；可见性为 `clear|unclear|not_visible`。质量值见脚本内 `QUALITY_VALUES`。

工具输出 `intake_only`；有图片仍为 `image_available_not_interpreted`，没有图片为 `not_observed`。PNG/JPEG 仅作容器结构检查，未解码像素；它不能判断图片实际有无手掌、掌纹、模糊、遮挡或滤镜，不能替代直接看图。只读取本地文件，不上传，不返回定位、设备或身份元数据；方向值仅用于解释显示宽高。

覆盖标注仅根据实际观察及显式坐标制作，具体合同、来源、镜像和隐私限制见 [图像观察与标注](../visual-observation.md)。质量还可显式记录 shadow 与 perspective；未知时保留 unknown。
