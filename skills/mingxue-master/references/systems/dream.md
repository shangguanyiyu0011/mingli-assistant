# 周公解梦：梦境与原典词条

独立入口 `dream`。实际功能是检索有来源的古文词条，再由当前 Agent 结合本人叙述写具体文化解读；它不是睡眠医学、心理诊断或现实事件预测引擎。

## 资料与来源

随包 `assets/classic-oracles/zhougong.json` 收录 [维基文库《周公解夢》固定 revision 7907671](https://zh.wikisource.org/w/index.php?title=周公解夢&oldid=7907671) 的27章、988条七字短句。每条保留稳定ID、章节、原文和来源行号；没有把章节下多句拼成一条，也没有加入现代网站的解释。原页明确标为 PD-old；站点的编辑性内容与古籍原作的公有领域状态分开处理。出处与摘要见 `zhougong-source.json` 及 [第三方资料说明](../third-party/README.md)。

这是固定电子转录本，原字与疑似误字不擅改，未逐页核影印底本；不把题署“周公”当成已经证实的历史作者。中英日韩名词检索键由本项目补写，便于检索同一原文，不是古文全译，也不新增吉凶判词。

## 本人输入

填写页提供每人独立的选填“梦境描述”，只收集梦见的经过、人物、物件和本人感受。协议为 `people[i].dream`，最多4000字符。没有梦境时不生成解梦章节。两人的梦分别检索，不根据共同问题、姓名、心理问卷或另一人的文字补梦。

只解梦可使用 `birth:null`，不要求出生日期、出生地、提问地或照片。填写了生日时仍执行原有日期与历法校验；综合任务缺出生资料时保留该事实，生日相关方法不生成虚构结果。

```json
{"mode":"single","people":[{"person":{"name":"虚构演示者"},"birth":null,"dream":"梦见一条蛇从桥边游进水里，我站在岸上看着。"}],"preferences":{"systems":["dream"],"language":"zh-CN"},"method_options":{}}
```

原生独立工具：

```text
python scripts/fortune.py dream --params '{"text":"梦见一条蛇从桥边游进水里。"}'
```

## 检索与正文

检索输出真实命中的词、古文、章节与来源。原文只是匹配材料，不能把出现同一名词视为整段梦完全相同。未命中的现代物件或特殊场景直接保留为用户叙述，不用其他条目随机兜底；不要虚构原典引文。

正文先说这场梦最突出的情节，再区分两层：原典如何描述相关场景，本人叙述中人物、动作、先后和感受有什么具体差异。相同物件在不同动作中的条目不能互换，更不能把相反的条目拼成笼统“有好有坏”。引用时保留原文和篇章；外语报告用所选语言解释，原文可另列。

不把古文中的病、死、财富或婚姻措辞当成对用户将来的事实，不据此诊病、诊断潜意识或给出心理类型。本人明确提到现实处境时，可讨论梦境与该自述的联系，但要保留这是本人关联，不包装成预测命中。报告只需一次简短文化参考提示，不在各段反复铺边界、介绍检索流程或写“最有内容的阅读来自词条”等套话。

梦的描述属于本人自述，原典命中属于文字资料。综合层按资料参考处理，不把命中词条数量加入多体系一致度，不作为独立的命盘预测证据。
