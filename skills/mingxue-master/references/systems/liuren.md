# 大六壬：课盘术语与审阅协议

状态：`reference_only`。本包未实现月将选取、天地盘、四课三传、昼夜贵人和九宗门的完整起课引擎。此模块支持概念、规则框架和用户所给课盘的阅读；不把小六壬六宫算法当作大六壬。

## 输入与流派

用户要解释既有课，只收课盘、占问范围和已知口径。用户要新起课时，说明尚缺起课引擎；不得临时用大六壬术语包装一个简单日期取模算法。

大六壬起课通常涉及占时、日干支、月将加时、天地盘、四课三传及天将。必须分清：

- 月将与月建不同；月将换将通常以中气为界，不能把农历月数直接当月将。
- 公历时刻、时区、地方钟表时或真太阳时、日界及节气时刻都可能影响盘。
- 昼夜贵人、贵人起例、涉害取法、寄宫和起课方式有流派差异，应明确采用口径。
- 占时与本命、生年、行年等资料分开；基础正时起课不自动要求所有个人资料。
- 用户说“现在”时，只有真正要调用可用引擎才读取真实当前时刻；不把聊天开始日期或历史时间作当前占时。

## 结构词表

| 层次 | 含义 | 可验证的材料 |
|---|---|---|
| 地盘 | 十二地支固定位置 | 课盘方位和排布 |
| 天盘 | 月将加占时等规则形成的地支对应 | 月将、占时、起课法与完整对应表 |
| 四课 | 围绕日干、日支及其上神的四层取象 | 干寄宫、干支上神及二次上神 |
| 三传 | 初传、中传、末传 | 取传法及由四课取传的过程 |
| 十二天将 | 贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后 | 贵人、昼夜、顺逆及实际落位 |
| 课体 | 按关系和取传形成的传统分类 | 必要条件和课盘中的实际证据 |
| 神煞、旬空、禄马等 | 辅助符号层 | 日干支等依据与查表口径 |

常见课体/取法术语包括贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟。它们有先后与适用条件；不能仅因天将中有“白虎”就宣布某课体或现实灾害。伏吟等术语也不能简化成保证某事拖延。

## 四课三传的阅读顺序

1. 先核对年月日时、时区、日干支和换将边界；用户给定值与另一个资料冲突时保留冲突。
2. 阅读完整天地盘，再确认四课。不能从不完整截图猜缺失的上神。
3. 明确实际使用的九宗门/取传步骤：哪里有上下克、是否需要比用或涉害等。无推导记录时，三传仅为用户提供值，不称重算验证。
4. 分开记录初、中、末三传各自的地支、天将、六亲/遁干等实际字段。
5. 再阅读课体、旬空、旺衰、禄马和神煞。单一符号不做结论，缺查表依据则不添加。
6. 采用传统赋文时，先核对准确原文、条目与适用条件；不以“其余类似”补造整部《毕法赋》。
7. 输出盘面关系、传统含义、相反条件和资料缺口，避免个人事件保证或伪概率。

## 传统符号的解释边界

贵人可作为援助主题、六合作为协作主题、朱雀作为表达或文书主题、玄武作为隐蔽主题、天空作为虚实主题等进行一般文化说明。名称不是对现实人物品德、是否犯罪或是否欺骗的事实判断。

三传的初、中、末可作为传统“发展阶段”的阅读框架，但不能直接定为三天、三个月或某个精确日期。应期必须有明确规则和实际推导，本模块未实现自动应期。不能由“白虎”“死气”等词诊断疾病、预言死亡或据此干预治疗；不能以盘断定诉讼胜负、投资收益或失踪者位置。

## 与其他模块的关系

小六壬、奇门、六爻是不同方法。用户要求合参时，分别保留各自占时、起法、盘面来源和结论，不能将一种方法的输出填入另一种方法的四课三传。同一模型用多个名称复述结论，不构成独立验证。
