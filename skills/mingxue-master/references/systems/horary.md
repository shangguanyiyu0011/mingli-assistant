# 卜卦占星：提问事件轮盘与结构

入口为 `scripts/astral_methods.py`，使用 `calculate("horary", params)`。必须明确提问内容、日期、时间、时区、经纬度；示例时刻不是自动认定的提问当下。默认 `house_system="R"`（Regiomontanus）是透明的界面选项，可显式改用已支持的宫制，不代表所有卜卦流派采用相同规则。

```powershell
python -X utf8 -B scripts/astral_methods.py horary --params '{"date":"2024-04-08","time":"18:00:00","timezone":"UTC","longitude":0,"latitude":51.48,"question":"这次沟通有哪些需要核实的信息？","quesited_house":3}'
```

时间先通过共享离线 IANA/schema 3 解析为物理 UTC，再用固定隔离星历计算真实行星、上升、天顶及宫头。轮盘显示十个实体，传统尊贵与相位结构只采用七曜，不把天王、海王、冥王星硬塞进古典守护表。本模块尊贵规则限定热带黄道。

`candidates[].dignities` 给出星座层面的入庙、擢升、失势、落陷；未计算三分、界、面、昼夜区分与偶然尊贵，不输出装成完整体系的总分，也不把“未列出尊贵”直接断成完整游走状态。守护表为七曜传统双守护，擢升只按星座，不将精确擢升度数或流派差别隐藏成默认。

`candidates[].aspects` 给出合相、六合、刑、拱、冲及实际角距、容许度。容许度沿用明确约定：六合 5°，其余 6°。入相/出相通过事件前后各 60 秒的真实星历，比较偏离精确相位的角误差，输出 `orb_change_deg_per_day`、`phase`、`phase_label`。这只是局部运动趋势；不保证行星会在换座、停滞、逆行或其他干预之前完成相位，不将它直接等同为事情必成/必败。

征象星结构为一宫宫头星座的传统守护星与月亮；所问事宜宫位只有在用户明确指定 `quesited_house=1..12` 时计算，不从自由文本强猜。宫位采用黄经区段显示，忽略行星黄纬；极地 Regiomontanus/Campanus 可能出现反向宫头顺序，本模块按实际顺序处理并记录区段方向，仍需复核几何条件。

输出包含可视 `wheel.points/houses/aspects`、完整 UTC 候选及规则元数据。分钟精度有独占终点采样，DST 重复钟点不任意选第一盘，缺时区或位置不补造。`judgement` 始终为 `null`；本模块不生成确定性裁决，也不提供死亡、医疗或投资结果预测。接纳、光线转移、完整相位完成搜索、月亮空亡等扩展判断尚未计算。
