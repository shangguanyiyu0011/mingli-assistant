# 西方数秘与姓名字母数

用于用户明确要求生命路径数、个人年度数、主数、Pythagorean 字母数等情况。保持与五格姓名学、八字五行的术语和依据分开。

## 工具与输入

```powershell
python -X utf8 -B scripts/symbolic.py numerology --date 1990-06-15 --year 2026 --masters 11,22,33 --method all-digits
python -X utf8 -B scripts/symbolic.py numerology --date 1990-06-15 --latin-name "Jane Doe"
python -X utf8 -B scripts/symbolic.py --probe
```

只依赖 Python 标准库，离线执行，stdout 为 JSON。日期必须是实际存在的公历 `YYYY-MM-DD`；检查闰日与年月日边界，不猜阴历转换或时区。年度数字仅在显式 `--year` 时计算，年份限定 1–9999，不隐式读取当前年份。

## 归约与主数约定

默认 `--method all-digits`，逐位加总公历年月日所有数字，再反复将数字位相加，直至个位或遇到配置的主数。默认 `--masters 11,22,33`；也可 `11,22` 或 `none`。只保留实际归约过程中遇到的主数，不为了讲解而拼出 11、22 或 33。每次输出原始数字、加总与归约 `trace`。

`--method component` 分别归约年、月、日，再加总归约；分项同样保留选定主数。两种约定可能不同：1999-01-04 在 all-digits 为 33，在 component 为 6。报告必须写出采用的口径，不把差异判为计算错误。

个人年度数用出生月、出生日与目标年份，沿用同一种方法和主数设置；以 1 月 1 日为年度边界。出生于 2 月 29 日时，在非闰年仍使用数字月=2、日=29，不制造一个目标年份的虚构生日。生日切换流派未由此工具实现，不能冒称支持。

固定核算示例：1990-06-15 的生命路径数字为 31→4；采用 all-digits 且保留 22 时，2026 个人年度为 22；若不保留主数则为 4。

## 拉丁字母姓名

`--latin-name` 可计算全部字母的表达数。映射为按 A–Z 顺序循环 1–9：

| 数字 | 字母 |
|---|---|
| 1 | A J S |
| 2 | B K T |
| 3 | C L U |
| 4 | D M V |
| 5 | E N W |
| 6 | F O X |
| 7 | G P Y |
| 8 | H Q Z |
| 9 | I R |

忽略空格、ASCII 连字符与单引号，大小写统一。仅接受 ASCII 拉丁字母；重音字母、其他文字、数字须由用户先明确给出所选转写。不猜汉字拼音，不把一个人的中文名自动转写成其英文名。输出完整映射、实际字母和逐字数值便于复核。当前工具不实现元音灵魂数、辅音人格数、迦勒底字母表或其他流派。

## 解读与输出

数值核算和象征联想分别呈现。可用主题、反思问题和可选择行动解释传统数字意象，避免把数字当作诊断性格、识别身份、预测事件或保证健康、投资收益的方法。用户指定流派未实现时，说明具体缺的规则或字表，仍可交付已算出的部分。

按需加 `--output` 保存到技能、runtime、cache 外的新绝对路径；不默认存储生日、姓名，也不覆盖已有文件。
