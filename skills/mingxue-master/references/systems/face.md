# 面相·麻衣相法：可见轮廓与传统部位名称

状态：`reference_only`。已整合三庭、五官及十二宫的传统词表和观察协议。面部照片只能支持可见外观描述，不能验证传统相术的个人预测。

麻衣的来源、五官名称映射、三庭端点与传本差异见 [麻衣相法](mayi.md)。它是同一 `face` 入口的传统框架，沿用本人的原照、观察和标注，不要求重复上传，也不计作另一套独立预测结果。

## 输入与观察范围

接受本轮用户提供的正面/侧面照片，或明确的文字描述。图片应由用户自愿提供；不要求身份证、姓名、生辰或其他身份信息。实际未看见图片时，写 `observation_status=not_observed`，不得把描述包装成视觉识别。

拍摄角度、焦距、表情、化妆、滤镜、发型、光照及裁切都会改变可见比例。发际被遮挡时不能量上庭；侧脸不能据此断言两侧对称；照片中看不清的耳朵不补造。只使用“较直/弯曲/圆/方/局部可辨”等中性词，不用“贵相”“恶相”评价被摄者。

不从照片推断性格、智力、道德、诚信、家庭关系、出身、职业、社会地位、财富、命运、疾病、精神状态或寿命。不推断种族、民族、宗教、性取向等敏感属性，也不以姓名、账户或个人记忆填充这些信息。照片也不足以判定骨骼内部结构或生殖能力。

## 三庭与五官词表

| 传统分区 | 一般位置口径 | 可以描述 | 必须保留的限制 |
|---|---|---|---|
| 上庭 | 发际至眉部附近 | 图中可见的额部轮廓和大致相对长度 | 发际、眉部及头部姿态影响测量 |
| 中庭 | 眉部至鼻底附近 | 图中鼻部轮廓、眉鼻间相对距离 | 不同文献端点不一，不能混用 |
| 下庭 | 鼻底至颏部 | 图中下颌及颏部轮廓、相对长度 | 表情、俯仰和透视影响明显 |
| 眉、眼、耳、鼻、口 | 可见五官外轮廓 | 形状、走向、局部遮挡 | 不从“大/小/厚/薄”转为人格或能力判断 |

三庭是传统分区，不是普适审美标准，也不是“早中晚年”真实测量尺。五官在部分相书中另称保寿官、监察官、采听官、审辨官、出纳官；这些名称仅用于辨认术语。“五岳”在相书中另有额、鼻、两颧、颏等分法，不能把五官与五岳直接当同一组。

## 十二宫文化索引

下面只说明传统命名和文献主题，不把照片外观与人生事实相连接。不同传本的范围有差异，应优先写可见部位，再附名称候选。

| 传统名称 | 常见部位 | 文献中的一般主题 |
|---|---|---|
| 命宫 | 眉间 | 总体处境的象征性标题 |
| 财帛宫 | 鼻部，部分传本偏鼻头 | 财用主题 |
| 兄弟宫 | 眉部 | 同辈主题 |
| 田宅宫 | 眉眼之间附近 | 居住主题 |
| 男女宫、子女宫 | 眼下区域 | 子女主题 |
| 疾厄宫 | 山根、鼻梁附近 | 健康主题的传统名称 |
| 迁移宫 | 额侧、眉尾外侧附近 | 出行主题 |
| 奴仆宫、交友宫 | 下颏两侧等 | 交往主题 |
| 官禄宫 | 额部中央附近 | 事务、职位主题 |
| 福德宫 | 眉上外侧等 | 生活境况主题 |
| 相貌宫 | 整体面部 | 整体相貌主题 |
| 父母宫 | 额部两侧附近 | 长辈主题 |

例如可说“眉间在某些传统文献中称命宫”，不可说“眉间较窄，所以你心胸狭窄或事业受阻”。也不能从眼下纹路推断子女数量、从鼻形推断财富、从唇形推断忠诚、从颧部轮廓推断婚姻。

## 工作步骤与输出

1. 确认资料为实际图片还是用户文字；不借身份或旧聊天推测照片事实。
2. 记录正/侧面、俯仰、遮挡、表情、滤镜及无法辨认的区域；无法确认则记“未知”。
3. 按面部轮廓、眉眼、鼻、唇、下颌分别写实际可见特征，说明具体形状及相邻部位的差异；不能只列“弯曲、圆润”几个词。光线、妆容或遮挡真正改变判断时，在对应部位一句说明。只有明确需要且图像足够时才谈粗略相对比例，不伪造像素测量。
4. 另列相关传统名称及一般文化主题，不对被摄者作主题上的个人预测。
5. 用户追问个性、智力、道德、家运、职业或健康时，继续说明照片不支持该推断；可转为用户自述经历的讨论，但不要把自述再归因到外貌。

私有观察记录结构：

- 资料状态：`image_observed` / `not_observed`。
- 图像限制：角度、遮挡、清晰度等。
- 可见描述：只列有图像依据的部位及形态。
- 传统术语：名称、对应区域和流派差异。
- 未能观察：缺失部位、不可从照片支持的推断。

报告正文直接按可见部位展开，不复制上述资料状态和缺项清单。传统名称紧接对应部位说明，不能用通用文化介绍替代本人照片的具体分析。

示例：“两侧面颊向下颌收拢，下颏末端呈圆弧，面颊到下巴的转折较柔和。下颏在部分传统分区中称地阁。”

## 本地工具

```text
python <skill_root>/scripts/visual_intake.py --system face --image <local.jpg> --observations <observations.json>
```

可用区域键为 `face_outline|forehead|eyebrow_outline|eye_outline|nose_outline|mouth_outline|ear_outline|chin_outline|visible_line`。形态和质量枚举见 [手相输入协议](palm.md) 或脚本。

工具不会识别人脸和五官，不比较身份，不估计年龄、性别或其他属性；只检查 PNG/JPEG 实际格式、尺寸及显示方向。质量值必须来自显式输入或后续实际看图，不能用尺寸检查冒充清晰度检测。EXIF 的定位、设备、姓名及拍摄时间等内容不返回、不上传。

覆盖标注仅根据实际观察及显式坐标制作，具体合同、来源、镜像和隐私限制见 [图像观察与标注](../visual-observation.md)。质量还可显式记录 shadow 与 perspective；未知时保留 unknown。
