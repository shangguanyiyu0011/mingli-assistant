# 风水：平面、朝向与传统空间符号

状态：`reference_only`。支持根据用户明确提供的平面、朝向和用途，整理空间信息、解释传统方位规则，并给出常识性的采光、通风和动线观察。本包未实现八宅命卦、玄空飞星、三合水法或自动罗盘测向，不称“自动排盘”。

## 输入与口径

基础信息是平面图或明确文字布局、北向标记、入口、门窗、各空间用途和用户关心的问题。没有北向时只分析布局与动线，不把图纸上方默认为北。没有比例尺时不估算实际通道宽度、面积或建筑尺寸。

- 说明是户型中心、单房间中心还是建筑整体；不跨层级混套宫位。
- 朝向以度数时，记录用户的测量方式、真北或磁北口径及误差；不从照片或城市名猜朝向。
- 区分“房屋朝向”“大门开口方向”“床头方向”“书桌朝向”，它们不能互相替代。
- 房间名称只代表用途，不推断入住者的性别、年龄、婚姻、辈分或关系。“主卧”不自动等于父亲与母亲同住。
- 多人使用时只采用用户明确的角色和需求；不以年龄、性别决定谁应住某方。
- 用户未要求流派细盘时，无需索取出生资料、建成年份或入伙时间；流派计算未实现时也不为此收集无用资料。

## 分两层给建议

### 使用体验和空间常识

只依据看得见或用户说明的条件：

- 入口与主要通道是否被家具阻挡，日常走动是否需要反复绕行。
- 使用位是否受到直接眩光、强逆光、噪声或持续穿堂风影响。
- 厨房、浴室等区域有无用户明确提到的通风、潮湿、异味问题；无资料则写“待确认”。
- 开窗、采光和遮阳能否按实际生活需要调整。
- 书桌、床及休息位的布置是否符合本人习惯和空间约束。

这些是一般使用体验观察，不作为建筑安全、消防、结构、燃气或健康的专业验收。涉及拆改、承重和设备施工时，保留专业核查需求，不能依据传统方位建议直接施工。

### 传统象征

明确标“某传统观点”，并指出并非已验证因果。例如门与通道的“聚散”、桌后“有靠”、水火的象征配合、八卦方位命名可作文化阅读。

不能把厨房某方位写为会伤害特定家庭成员，不能根据卫生间方位断疾病、婚姻或生育。也不保证摆件能招财、化煞、改变命运，不以此诱导购买、搬迁、换房或大额装修。传统的“好/坏”标签不能代替具体通风、采光和使用条件。

## 流派边界

| 流派/方法 | 需要的额外前提 | 当前处理 |
|---|---|---|
| 形势、动线阅读 | 平面/环境资料和使用需求 | 说明观察与传统比喻的区别 |
| 后天八卦九宫 | 北向、中心、尺度口径 | 可人工解释符号，不称自动定盘 |
| 八宅 | 明确流派、坐向/命卦算法等 | `reference_only`，不自行套算法 |
| 玄空飞星 | 运盘口径、建成/入伙等时间、坐向及山向边界 | `reference_only`，未排运山向三盘 |
| 三合、水法、二十四山 | 现场测向及流派规则 | `reference_only`，不从普通照片臆造 |

## 报告协议

输出依次为“已知平面与朝向”“待确认与误差”“使用体验观察”“传统符号解释”“可逆的小调整”。每条调整写对应的具体问题、依据及约束。可以建议调整照明或家具试摆后观察实际体验；不要把改善归因于财运变化。

用于记录的字段：`status=reference_only`、`layout_source=user_provided`、`north_basis`、`center_method`、`room_uses`、`practical_observations`、`traditional_symbols`、`uncertainties`。未有数据的字段标未知，不生成伪宫位、伪飞星或虚构方位。
