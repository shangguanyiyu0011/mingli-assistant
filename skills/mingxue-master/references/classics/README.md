# 核心古籍证据卡

本目录提供16条有限范围的可定位文本证据。《子平真诠》据国图藏世界图书馆发行本扫描页核对；《滴天髓》与《神峰通考》据带固定修订号的公开原文录文核对。每条卡列出书名、篇章、位置、短引句、转述、直接支持和不支持的判断，以及来源版本与访问日。

先在 `index.json` 按 evidence_id 或篇章选择相关卡，再沿 source_id 查看原文来源。PDF页码从1开始；原书页码另列。`text-checks.json` 是本次短引句核对记录，供离线完整性检查；测试通过不等于重新联网校勘，也不核验历史人物生辰。

`verified_text` 只用于已经看过的指定短引句及相关段落。它不表示全书已校、所有版本相同、缺失提炼稿已恢复，或命理具有现实预测效度。既有提炼文档仍按各自证据状态使用；本目录不能替它们整篇背书。

《滴天髓》本次核对的是《滴天髓辑要》电子录文，不把这些卡冒称为对《滴天髓阐微》全部原文的核验。古籍中的用神、体用和相神各有语境，应用时须说明采用的篇章与前提。
