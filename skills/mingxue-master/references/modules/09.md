# 09 命理约言

- `references/upstream/mingli-yueyan-skillpack/yueyan-biange/MODULE.md` — 当须先确认正格不成立才论从化，总纲在yueyan-kanning；日主有根可扶者及问婚姻财运等具体事项不用此技能。
- `references/upstream/mingli-yueyan-skillpack/yueyan-duanshi/MODULE.md` — 先经yueyan-kanning定格局，格局细则转yueyan-shishen；性情疾病女命小儿转yueyan-xingqing-nvming；问创业投资等现代职业本书不覆盖。
- `references/upstream/mingli-yueyan-skillpack/yueyan-kanning/MODULE.md` — 断八字总入口：日干强弱→月令取格→用神扶抑→运岁→清浊。细则转yueyan-shishen，变格转yueyan-biange，断事转yueyan-duanshi，性情疾病女命小儿转yueyan-xingqing-nvmi……
- `references/upstream/mingli-yueyan-skillpack/yueyan-shishen/MODULE.md` — 当按月令定十神格局，查成格破格、取用神、克破与行运。需先做格局判定，总纲在 yueyan-kanning；从格化格走 yueyan-biange；问婚姻财运另有专门技能。
- `references/upstream/mingli-yueyan-skillpack/yueyan-xingqing-nvming/MODULE.md` — 用户问性格脾气、身体疾病、女命婚姻夫星子息、小孩命格时使用：性情看五行清浊偏正，疾病看五行偏弊伤脏腑，女命先定格局再查夫星子星，小儿看根基不谈关煞。须先过 yueyan-kanning 定格局；问富贵层次走 yueyan……
