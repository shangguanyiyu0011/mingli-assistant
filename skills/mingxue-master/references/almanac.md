# 黄历表与择日范围

`scripts/almanac.py` 实际查询包内中国历法表，可按一个或最多31个连续公历日期列出宜忌、值日、冲煞及可选时辰宜忌。输入按中国UTC+08日历日，不把外地钟点自动套入。未给时刻只查询日期表，不补造时辰结果。

```text
python scripts/almanac.py --date 2026-11-01 --days 7 --topic 嫁娶
```

`--topic` 按表中的原有术语精确检索，返回“是否列于宜/忌”，不自动选出个人吉日。此能力不包括全流派择日、婚配、动土或用事本命推算；也不把传统标签当作现实风险和结果保证。医疗安排、法定期限及实际安全要求仍按现实需要处理。

日宜忌采用日期级交节月界（sect=1），同一公历日不因查询钟点而改变；日柱按零点换日。可选时辰表采用库自身23点换日约定，字段单独标明，不将两套边界混为一个时刻规则。
